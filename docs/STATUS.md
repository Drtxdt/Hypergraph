# Hypergraph v1

实现范围、固定来源和新配置映射见 [功能矩阵](FEATURES.md)，测试条件与验证边界见 [验收记录](ACCEPTANCE.md)。244 个来源配置组已建立等价实现映射，没有 pending 或 partial 项。

交付物包括可安装 npm 主题包、公开演示源站与静态站、完整配置参考、扩展和预设示例、Waline 托管模板及本地博客迁移工具。所有客户端资源预编译，使用者不需要运行 Vite。

公开演示与三篇加密测试、真实博客内容分开。`.local/` 保存测试报告、私人迁移备份和验证站，不进入发布包。生产 Waline 服务地址及其他外部账号由站长填写；没有自动发布网站或创建托管账号。

Node.js 最低声明为 22.12，实际验收使用 22.14 / 24.18；Hexo 使用 7.3 / 8.1。性能数据为受控实验室测量，真实用户指标须在上线后观察。
