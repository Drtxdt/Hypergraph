# beta.9：阅读与资料界面

无图首页将同名标题和打印字标合并，精选文章承担主要视觉层级。阅读纸面保护连续正文，地形采用拉长山脊与谷地，手机保留单角构图。

打印保留开场后 1600ms 时间线，字标使用站点展示字体与主题色；照片保持完整底图并叠加材质扫描。离屏目标直接恢复静态完成态。

搜索结果显示日期、分类和关键词强调。输入框内上下键选择结果、Enter 跳转；旧搜索索引仍可使用。手机音乐首次收起，主动播放后保留迷你播放条。

文章开头封面默认关闭；音乐默认关闭。现有 contour、artwork、intro、motion 和 laser_print 配置继续生效。
