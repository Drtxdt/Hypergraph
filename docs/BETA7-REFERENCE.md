# beta.7 视觉依据与改编边界

| 证据 | 可确认的内容 | 本主题采用方式 |
|---|---|---|
| 官网 WACZ 中的已校验图片与样式 | 不规则闭合地形、方向性流线、边缘构图 | 原创解析高度场和 marching squares；不分发参考图片 |
| 用户提供的 2026-11-01 录屏 | 自下而上扫描，前沿附近亮点和短射线，已形成部分保持稳定，结束后停止 | 840ms 局部时间线，与已有全屏揭幕重叠；站名保留普通 DOM |
| review 中的实现提示 | 闭合路径保留、减少动态、生命周期、素材替换等验收方向 | 独立静态 SVG、构建期目标点、按需模块、统一清理 |

840ms、粒子预算、移动端取景和本主题的 60% 停顿时长是项目设计值，不作为官网实测时序。录屏未提供 HTML 源码，未把演示 HTML 当作已取得的源码。参考仓库仅用于分析，未引入另一套主题状态管理或复制其生成器。

等高线和三层折面均为项目原创。`examples/visual/source/images/print-mark.svg` 与 `print-mark.png` 是原创透明素材测试图，随项目 MIT 许可分发。照片授权见 `examples/content/README.md`。

新截图是执行者检查用的候选证据；自动几何断言、过程录像、人工画面检查和用户确认是不同记录。此轮不自动覆盖旧像素基线，不声称已获得新的用户视觉确认。
