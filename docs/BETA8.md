# beta.8：持续地形与站点打印

无图首页保留 `home.title` 和简介，独立字标读取站点 `_config.yml` 的 `title`。配置主图时使用主图，否则依次使用 `home.masthead.artwork.image`、`site_logo`、文字字标。关闭 `show_cover` 使用文字字标；关闭 artwork 则不显示装饰对象。

`appearance.contour` 继续使用 `enable / style / opacity / scope`，风格为 `terrain / flow`。固定双角地形位于稳定外壳，手机单角；阅读内容在纸面上。没有滚动动画或新增粒子调参选项。

全屏开场保持原有 60% 停顿、黄色扫满及淡出，共约 2400ms。局部打印在完整开场结束后播放 840ms，经历入射、沉积、残留和稳定。标题、导航和正文不等待局部打印。摄影图始终保留底图；装饰对象只在仍被开场完全遮挡时准备揭露，迟到资源保留静态完成态。

减少动态、省流、关闭动效、历史恢复、跳过开场和资源错误使用静态内容。无 JS 保留字标或图片。字体、窗口尺寸、图片候选或主题变化会结束当前打印。SVG 作为图片读取，不将用户 SVG 源码注入 DOM。

地形资产为原创标量场等值线，拼接后简化和平滑；闭合地形保留。素材、边缘构图及动画时长为本主题的设计，不代表官网原始实现。

开发验收包含 `npm run verify`、运行环境矩阵、当前安装包消费者测试、`node tools/verify-showcase.mjs` 和真实 Pages 检查。新证据保存在 `.local/beta8`；历史批准的像素基线不会自动覆盖。
