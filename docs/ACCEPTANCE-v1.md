- 连续 30 次增强导航、历史返回、请求失败和重试：同一已开始播放的音频实例保持播放。普通完整页面导航也通过。

- 独立 npm 扩展安装、停用、页面重挂载与 API 版本校验，以及独立预设模板升级检查通过。
- Waline SQLite 实例完成匿名写入、读回；数量、最新评论、弹幕与减少动态效果通过。其他 11 个评论客户端完成加载、故障隔离与页面清理的契约测试；延迟加载和双服务切换通过。

外部评论、统计、聊天、AI 摘要与朋友圈服务使用契约响应或受控故障验证；这不等同于所有第三方生产账号的端到端验证。生产账号、域名、额度由使用者配置，异常不会阻断正文。

## 性能

Edge，390×844，CPU 4 倍降速，150 ms RTT，下载 1.6 Mbps；首页及真实长文各 3 次冷加载，并操作移动菜单、明暗切换、搜索输入及关闭。

| 指标 | 实测 | 门槛 |
|---|---:|---:|
| 首页 LCP | 816–860 ms | ≤2500 ms |
| 长文 LCP | 976–1080 ms | ≤2500 ms |
| CLS 最大值 | 0.0121 | ≤0.1 |
| 实验室最大交互耗时 | 120 ms | ≤200 ms |
| 默认初始 JavaScript gzip | 17,568 bytes | ≤60 KiB |
| 默认初始 CSS gzip | 5,146 bytes | ≤40 KiB |

默认页面无可选模块或跨域资源请求。图形、评论和简繁词典等大型模块按需加载；安装包大小不等于首屏下载量。实验室 Event Timing 不能替代上线后的真实用户第 75 百分位 INP。
