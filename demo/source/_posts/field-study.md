## 从观察开始

好的记录不急于给出答案。它先留下现场：光线落在哪里，路径如何转折，人与空间如何相遇。

我们需要的不是更多装饰，而是让内容拥有自己的位置。标题建立入口，正文延续思考，边缘的信息在需要时提供方向。

> 清晰的结构，应该容得下尚未完成的想法。

## 信息的层次

不同的信息有不同的阅读速度。日期与分类可以快速扫描，叙述需要连续的节奏，而代码和公式需要独立的空间。

| 层次 | 作用 | 阅读方式 |
| --- | --- | --- |
| 标题 | 建立主题 | 一眼识别 |
| 正文 | 展开观点 | 连续阅读 |
| 注释 | 补充背景 | 按需查阅 |

### 为变化留下余地

不把每一块空间填满，也不为不存在的图片保留空框。内容的多少，本身就应参与版面的形成。

```typescript
const journal = { title: 'Field notes', entries: [] };
function record(thought: string) {
  return { ...journal, entries: [...journal.entries, thought] };
}
```
