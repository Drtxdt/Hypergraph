一个博客会经历很长的变化：最初只有几篇笔记，后来出现项目、照片、书摘和生活记录。页面应该容得下这些变化，也应该让第一次来访的人迅速找到值得阅读的内容。

这篇文章同时是一份可阅读的主题示例。你可以向下浏览，观察边缘地形如何陪伴正文，打开目录跳转，或者切换深色模式，检查代码与图片是否仍然清楚。

## 从真实的名字开始

站名和首页标题可以承担不同职责。站名回答“这是谁的空间”，标题则表达“这里记录什么”。例如，站名可以是自己的笔名，而首页标题写成“沿途记录”或“记录当下，连接未知”。两者不必使用同一句话。

Hypergraph 将文字字标作为没有图片时的默认视觉对象。它读取站点名称，因此新站不需要先找到一张插画才能成立。已有标识可以替换字标，首页主图则适合展示有明确主体的照片或作品。

首页的简介最好写得具体。与其列出许多宏大的领域，不如告诉读者最近在做的事情、习惯记录的内容，以及可以从哪里开始阅读。栏目入口同样需要真实的文章支撑，文章数量很少时，保留两个清楚的入口就足够。

## 让图片拥有自己的位置

横向风景、竖向肖像和透明标识需要不同的构图方式。横图可以铺满一个画框，但人物肖像经常需要完整显示。选择图片之后，应分别检查桌面和手机，确认重要部分没有被裁掉。

```yaml
home:
  title: 沿途记录
  description: 风景、作品与现场。
  masthead:
    image:
      src: /images/landscape.jpg
      fit: cover
      position: 50% 50%
      mobile_position: 65% 50%
      alt: 岩层与峡谷在远处展开
```

`cover` 会填满画框，允许裁切边缘；`contain` 保留完整图片，剩余空间成为构图的一部分。手机位置单独设置，是因为窄屏上的画框比例可能与桌面不同。

替代文字描述图片传达的信息，图说则可以补充拍摄地点、作品名称或来源。两者服务于不同的阅读情境，不需要机械地重复文件名。

## 地形是一种持续的环境

地形纹理的作用不是盖满整个页面。它更像书页旁边留下的一段地貌：边缘具有方向，中心留给文字；有的曲线收紧成带，有的在转弯之后展开。

当读者滚到文章中段时，环境仍然在场。这种连续感不需要纹理一直运动。静止的边缘可以提供稳定的参照，正文、插图和代码按照阅读顺序向上移动。

```yaml
appearance:
  contour:
    enable: true
    style: terrain
    opacity: 0.18
    scope: site
```

如果站点图片已经具有丰富的纹理，可以降低地形浓度，或选择更舒展的 `flow`。调整时优先看文章中段，而不是只看首页顶部：长时间阅读是博客更常见的使用方式。

## 阅读纸面承担什么

正文需要稳定的明暗关系。代码中一个符号的差异、表格中一行数据的对应，都比装饰更重要。背景图片与地形可以出现在边缘，阅读区域则提供清楚的纸面。

下面这段代码展示了普通的记录流程。可以使用代码框上的复制按钮，也可以直接选中文字。较宽的代码会在框内滚动，不会把整张页面撑宽。

```javascript
const notes = [
  { title: '一次散步', category: '生活', published: true },
  { title: '项目草图', category: '设计', published: false },
  { title: '阅读摘记', category: '阅读', published: true },
];

const visibleNotes = notes
  .filter(note => note.published)
  .map(({ title, category }) => ({ title, category }));

console.table(visibleNotes);
```

| 内容 | 建议的展示方式 | 阅读重点 |
|---|---|---|
| 长篇技术笔记 | 标题、目录、代码与图解 | 快速定位和反复查阅 |
| 摄影记录 | 主体明确的图片与简短图说 | 图片完整性与观看节奏 |
| 项目总结 | 背景、过程、结果与后续问题 | 理解决策及其依据 |
| 日常短记 | 日期与自然段落 | 保留具体的观察 |

## 动作结束以后

动画应该有明确的终点。进入首页时，开场结束后，局部对象完成一次有方向的打印；随后画面安静下来，读者可以继续浏览。标题和正文不需要等待局部动作结束。

减少动态效果的访客会直接看到静态结果。资源加载较慢时，页面也保留完整内容，不会在已经开始阅读后突然隐藏图片。好的动效不是要求每个人必须观看的节目，而是一种可以自然退场的辅助表达。

## 给以后的自己留下入口

内容越多，归档和分类越有价值。分类可以保持少而稳定，标签用来连接跨越分类的主题。写完一篇文章后，补上一段能够独立理解的摘要，会帮助未来的自己重新找到它。

维护一个个人空间不必从复杂的规则开始。先选定清楚的名字，放入几篇真实内容，检查手机上的阅读体验，再随着写作逐渐调整。页面最终的辨识度来自持续积累的作品与观察。

这也是这份示例希望展示的状态：有足够明确的视觉身份，也有足够安静的空间，让下一篇文章能够自然地加入。
